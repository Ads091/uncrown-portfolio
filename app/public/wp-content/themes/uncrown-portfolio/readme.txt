UNCROWN PORTFOLIO — WORDPRESS THEME, VERSION 1.4.4

A black-and-gold portfolio theme built around the UNCROWN logo. It is a separate theme from
"OG Team Portfolio" and "Capstone Team Portfolio", but uses the same Team Members, Projects,
Project Categories and contact form, so your published content appears as soon as you activate it.

LOOK
- Dark only: a black stage lit by gold, silver type, the logo's crown and gold ring as recurring motifs.
- Fonts from Google Fonts: Tektur (headlines), Outfit (text), Geist Mono (labels).
- The UNCROWN logo is included with a transparent background (assets/images/uncrown-logo.png)
  and as an emblem for the header and favicon-sized uses (assets/images/uncrown-mark.png).

CINEMATIC SCROLL INTRO
- The homepage opens with a full-screen, scroll-driven film drawn live in the browser:
  1. a beam of light with gold dust   2. orbiting gold rings (from the logo's ring)
  3. ranges of crown peaks             4. a gold arena floor with light pillars
  5. a giant crown with rising embers  6. the logo, your headline and buttons
- Between scenes a gold particle warp plays; headlines build in letter by letter.
- Edit the five headlines in Appearance > Customize > Uncrown Homepage > "Scroll intro — scene N headline".
- "Skip intro" jumps straight to the content. Visitors who reduce motion see a still hero instead
  (assets/images/story-poster.jpg). Tick "Turn off the cinematic scroll intro" to use the simple hero for everyone.
- Optional: upload a short silent MP4 as "Hero background video"; it plays behind the first scene.
- No external libraries: everything runs on the theme's own scripts (assets/js/scenes.js and main.js).

NEW IN 1.4
- Home link added to the header menu and the footer.
- Menu links (Team, Process, Work) now land with the section heading just below the header.
- Social links: Appearance > Customize > Uncrown Social Links. Paste your Facebook, Instagram,
  X (Twitter) and GitHub addresses. Each filled-in one appears as an icon button in the intro's last
  scene, in the Contact section ("Follow the team") and in the footer. Empty ones stay hidden.

PROJECT PAGES AS PRODUCT LANDING PAGES (1.3)
- Each Project has three optional app-screen slots: Web app (browser frame), Tablet app (tablet frame)
  and Phone app (phone frame). Pick a short, silent MP4 for each with "Choose from Media Library",
  and add a label as "Title: one-sentence description".
- The project page then shows: the project name sliding across as a huge outlined marquee, all devices
  flying together into one scene as you scroll, a pinned section where the device switches between
  web, tablet and phone as you read about each app, then Key features cards and Built with tags.
- Videos play only while on screen and never for visitors who reduce motion. On project cards the
  web video plays on hover (or while in view on phones).
- "Key features": one per line, "Title: short explanation".

SKILL LEVELS (1.1)
- Each Team Member has a "Skill levels for the charts (0–100)" box. Enter one skill per line:
    Java: 80
    HTML: 95
    CSS: 90
    JavaScript: 75
    PHP: 70
- The member's profile shows every skill as a bar; their card on the homepage shows their top three.
- The homepage "Team skills" chart combines everyone: each bar is the average of the members who
  listed that skill, each dot is one member. Hover a row to see every member's level; "View as table"
  shows the same numbers as a table. Skills are matched by name, so spell them the same way for everyone.
- Members with an empty box keep showing their plain skill tags instead.

OTHER CHANGES IN 1.1
- "Roster" is now "Team" in the menu, section, buttons and links (the section address is /#team).
- The floating header and the scroll intro now sit below the black WordPress admin bar when you are logged in.

INSTALL
1. Appearance > Themes > Add New > Upload Theme, choose uncrown-portfolio.zip, Install, Activate.
2. Appearance > Customize > Uncrown Homepage: check the team name ("Uncrown"), headline and
   description, and enter the team Contact email (Customizer settings are stored per theme).
3. If /projects/ shows a 404, go to Settings > Permalinks and click Save Changes once.
4. Your previous theme stays installed; switch back any time from Appearance > Themes.

MENUS
With no menu assigned, the header shows Home, Team, Process, Work and Say hello. Assign a menu to
"Primary Menu" in Appearance > Menus to replace those links.
